Servers That Just Run

These servers enable me to experiment with new projects from the open-source community and host my own cloud services, eliminating the need to rely on commercial providers.

Why Self-Host?

Self-hosting gives me full control over my data and frees me from annoying monthly subscriptions. I’m responsible for maintaining the quality of the service, and I genuinely enjoy the process of learning about computer networking and keeping my server running smoothly. It’s a hobby that demands a lot of time and effort to develop the necessary skills, skills that can only truly be learned through hands-on experience.

The Apps

NetData

Netdata is a great tool for logging and monitoring system metrics. I don’t have much to say because it has worked flawlessly for me so far.

Nginx Proxy Manager

Simple and easy-to-use Reverse Proxy Manager. But I am looking into Traefik as it is more secure and has load-balancing.

PaperlessNGX

PaperlessNGX Helps me index all my documents and PDFs allowing them to be easily accessible from any device.

UpSnap

Just a simple docker that allows me to perform wake-on LAN requests through a well-crafted web interface.

Lychee

A Simple Docker applet that allows me to share my gallery in high quality, Access it HERE

Fireshare

Fireshare lets me and my friends share our game clips without any upload size limits.

Crafty

A no muss, no fuss Minecraft server manager that just works.

Automatic1111

Automatic 1111 is a web-based GUI for stable diffusion generative image generation.

Open Web UI

Open Web UI is a web-based GUI for Ollama, a Large language model manager, Open Web UI allows me to chat with the LLMs running on my Ollama instance.

NetBootXYZ

NetBoot.xyz turned my Ventoy boot USB stick obsolete overnight. It offers a wide range of bootable installers and rescue tools via PXE boot over LAN.

OpenSpeedTest

Simple Speedtest applet that just works, its really cool to see the internet speed between my server and some locations.

Portainer

Fuss-free docker manager that works almost too well.

Alist

Google Drive alternative for me to access my files while using my own storage.

Immich

Google Photos alternative for me to access my photos while using my own storage and also back them up!

Syncthing

The most Goated piece of software to ever exist, backups, versions, syncs my files between devices.

Nginx

Lets me run this very website you are on right now!
